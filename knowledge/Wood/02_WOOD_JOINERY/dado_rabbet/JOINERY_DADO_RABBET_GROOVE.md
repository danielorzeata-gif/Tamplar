# JOINERY — DADO / RABBET / GROOVE / TONGUE & GROOVE (Canal transversal, falt, nut, lamba si uluc)

Termeni (US / UK / RO):
- **Dado** (US) = **housing / trench** (UK) = canal transversal pe fibra → vezi si `housing/`.
- **Groove** = nut longitudinal (in lungul fibrei).
- **Rabbet** (US) = **rebate** (UK) = falt (degajare la margine).
- **Tongue & groove** = lamba si uluc (nut si feder).
