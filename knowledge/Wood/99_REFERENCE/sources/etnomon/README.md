# ETNOMON — set de date derivat

- `ETNOMON_constructii_clasificate.json` — 1.047 constructii din ETNOMON (Institutul National al Patrimoniului), cu campurile clasificate (judet, zona, specii, imbinari, barne, talpi, acoperis, invelitoare, text original al peretilor).
- `crawl.py` — descarcarea fiselor (o cerere la ~0,6 s); `analyze2.py` — clasificare si tabele: `python analyze2.py records.jsonl out.md`.
