# TOOL — JAPANESE TOOLS (scule japoneze)

Sursa principala: Toshio Odate, *Japanese Woodworking Tools: Their Tradition, Spirit and Use* (1984) `[REF]`; Hideo Sato & Yasuo Nakahara, *The Complete Japanese Joinery* (Hartley & Marks, 1995) `[REF]`; Coaldrake *The Way of the Carpenter* (1990) `[REF]`.

| Scula | Kanji | Tip | Note practice |
|---|---|---|---|
| Ryoba | 両刃 | ferastrau cu doua taisuri (rip pe o parte, crosscut pe cealalta), trage | universal; fara spate |
| Dozuki | 胴付 | ferastrau cu spate, dinte fin crosscut | umeri de cep, dovetail, kumiko |
| Kataba | 片刃 | ferastrau cu un singur tais, fara spate | taieturi adanci |
| Azebiki | 畔挽 | ferastrau mic cu panza curba | incepe taietura in mijlocul panoului (canale, scobituri) |
| Kanna | 鉋 | rindea cu corp de lemn (kashi), lama groasa laminata + contralama (uragane) | se trage; talpa se ajusteaza (dai-naoshi) cu sezonul |
| Nomi | 鑿 | dalti: **oire-nomi** (banc, uz general), **tataki-nomi** (grea, pentru ciocan, scobituri), **tsuki-nomi** (lunga, de impins/pariat, dulgherie), **mukomachi-nomi** (de scobit, sectiune groasa), **shinogi-nomi** (colturi ascutite, dovetail), **kote-nomi** (gat cotit) | otel dur (hagane) laminat pe fier moale (jigane); spate concav (ura) |
| Genno | 玄能 | ciocan cu doua fete (una plata, una usor bombata) | fata bombata la final ca sa nu marcheze lemnul |
| Sashigane | 差し金 | echer de dulgher din otel, cu scala in sun si scala "ura-me" (×√2) | ura-me citeste direct latura patratului inscriptibil intr-un bustean |
| Sumitsubo | 墨壺 | ata cu tus (chalk line japonez) | trasarea axelor (shin-zumi) |
| Sumisashi | 墨刺し | "pensula" din bambus pentru trasare cu tus | |
| Kebiki | 罫引 | gramil (cu cutit) | |

**TOOL-JP-001** — Ferastraul care trage lucreaza in tractiune → panza poate fi subtire → taietura ingusta si control fin; dezavantaj: dintii fragili in noduri/esente foarte dure. `[REF]` Odate.
**TOOL-JP-002** — Kanna se trage; talpa trebuie corectata periodic (corpul de lemn se misca cu umiditatea). `[REF]` Odate.
**TOOL-JP-003** — Lama laminata: hagane dur (tais), jigane moale (absoarbe socuri, se slefuieste usor); ura (spatele concav) limiteaza suprafata de lepuit. `[REF]` Odate.
