# sashimono — imbinari de mobilier — 指物の仕口 — Cabinetmaking joints: hako-ari, kakushi-ari, sanmai-gumi, hira-hozo

ID: JP-15 · Categorie: sashimono

|---|---|---|
| 1 | Nume | **sashimono — imbinari de mobilier** (指物の仕口) — EN: Cabinetmaking joints: hako-ari, kakushi-ari, sanmai-gumi, hira-hozo |
| 2 | Sinonime | vezi geometrie / variante |
| 3 | Geometrie | Hako-ari-gumi (coada de randunica de cutie); kakushi-ari-gumi (coada ascunsa cu mitre — imbinare invizibila); sanmai-gumi (furca/bridle); hira-hozo (cep plat); tome-hozo (mitre cu cep ascuns). Sashimono = mobilier asamblat fara cuie, cu imbinari precise. |
| 4 | Piese | placi de cutie/dulap (tansu), rame. |
| 5 | Fibra | Ca la dovetail european. |
| 6 | Dimensiuni | `[REF]` — Odate; Koizumi *Traditional Japanese Furniture*. |
| 7 | Tolerante | Foarte stricte; se lucreaza cu kanna pentru ajustari finale. |
| 8 | Rezistenta | Ca echivalentele europene. |
| 9 | Avantaje | estetica; fara metal. |
| 10 | Dezavantaje | manopera. |
| 11 | Scule | dozuki, nomi (oire-nomi, shinogi-nomi pentru colturi ascutite), kanna, kebiki. |
| 12 | Metoda manuala | Trasare cu sumitsubo + sashigane pe axe (shin-zumi), nu pe fete — compenseaza lemnul neregulat; taiere cu nokogiri pe partea de deseu; curatare cu nomi; proba de asamblare. `[REF]` Odate; Coaldrake |
| 13 | Metoda cu utilaje | Masini pre-cut (purekatto) CNC pentru dulgherie — azi majoritatea caselor din Japonia; in atelier: freza cu sabloane, freza de lant. `[REF]` |
| 14 | Aplicatii | tansu, cutii, rame de usi glisante (fusuma/shoji). |
| 15 | Lemn | kiri (paulownia — usor, stabil, cutii), keyaki, kuri, hinoki. |
| 16 | Adeziv | De regula **fara adeziv** (imbinare mecanica, demontabila, reparabila). In mobilier sashimono: uneori clei de orez (sokui) — `[REF]` |
| 17 | Defecte | ca la dovetail. |
| 18 | Reparatii | ca la dovetail. |
| 19 | Echivalent / alternativa | EU: through/half-blind/secret mitred dovetail (vezi `02_WOOD_JOINERY/dovetail`). |
